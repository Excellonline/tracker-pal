Before you start

Your package details stay in Chrome

TrackerPal stores the package name, tracking number or optional pickup address, carrier, status, and received state locally in this Chrome profile. TrackerPal does not send that list to a developer-owned server.

When you click a package's carrier button, Chrome opens the carrier's website and includes that package's tracking number in the carrier URL.
