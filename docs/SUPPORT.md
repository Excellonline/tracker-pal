# TrackerPal Support

TrackerPal is a local package tracker for Chrome's side panel.

## Quick fixes

- **The side panel does not open:** Update Chrome to version 114 or newer, then click the TrackerPal toolbar icon again.
- **A carrier is not detected:** Choose the carrier manually when adding the package.
- **A tracking page does not open:** Check that the tracking number is complete, then try the carrier's official website directly.
- **Reset TrackerPal:** Open the **Privacy** link in TrackerPal and choose **Delete all TrackerPal data**.

## Get help

Report a problem through the [TrackerPal issue tracker](https://github.com/Excellonline/tracker-pal/issues). Do not include real tracking numbers, deployment URLs, email contents, or account credentials in a public report.
